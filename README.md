# Dashboard de Vendas

Projeto de portfólio de análise e visualização de vendas, estruturado para prática com Excel e Power BI.

## Objetivo
Transformar dados de vendas em indicadores úteis para acompanhamento de faturamento, pedidos, produtos, regiões e desempenho comercial.

## Tecnologias e conceitos
- Microsoft Excel
- Power BI
- Power Query
- DAX
- CSV
- KPIs
- Tabelas dinâmicas
- Segmentação de dados
- Modelagem e análise de dados

## Indicadores
- Faturamento total
- Quantidade de pedidos
- Ticket médio
- Quantidade de itens vendidos
- Faturamento por categoria
- Faturamento por região
- Evolução mensal
- Ranking de produtos
